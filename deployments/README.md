# Deployment Artifacts

This directory contains network-specific deployment artifacts generated by the deployment scripts.

## Structure

```
deployments/
├── testnet/
│   ├── carapace.json       # Carapace deployment on testnet
│   └── hatch.json          # Hatch deployment on testnet
├── mainnet/
│   ├── carapace.json       # Carapace deployment on mainnet
│   └── hatch.json          # Hatch deployment on mainnet
├── devnet/                 # Development network deployments
└── localnet/               # Local network deployments
```

## Artifact Format

Each deployment artifact is a JSON file containing:

```json
{
  "name": "hatch",
  "network": "testnet",
  "packageId": "0x...",
  "digest": "...",
  "timestamp": "2025-11-01T15:48:15.000Z",
  "deployer": "0x...",
  "gasUsed": "...",
  "dependencies": {
    "carapace": "0x..."
  }
}
```

## Usage in SDK

```typescript
import { loadDeployment, getAllDeployments } from '../deploy/helpers';

// Load specific package
const hatch = loadDeployment('testnet', 'hatch');
console.log(hatch.packageId);

// Load all deployments for a network
const allDeployments = getAllDeployments('testnet');
```

## Git Strategy

- **Testnet**: Commit artifacts for team collaboration
- **Mainnet**: Definitely commit artifacts for production reference
- **Devnet/Localnet**: Don't commit (local development only)

## Auto-Generated Files

These artifacts are automatically generated by:
- `bun run deploy` - Main deployment script
- Individual deployment scripts in `deploy/` directory

Do not manually edit these files.
